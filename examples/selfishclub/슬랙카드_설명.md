# 슬랙 카드는 이렇게 생겼어요

> 캡처는 발표 장표에 있어요. 여기엔 구성만 적어요. (캡처 파일을 넣을 자리: `examples/selfishclub/card-*.png`)

## 카드 한 장의 구성 (위에서 아래로)

| 칸 | 내용 | 왜 |
|---|---|---|
| **유형 · 상태** | 예: `VOD · 사람이 봐야 해요` / `링크미수신 · 초안 있음` | 알림 미리보기에 유형과 요약이 먼저 보이게 |
| **한 줄 요약** | 40자 안. 「회원이 다시보기 링크 어디서 보는지 물었어요」 | 카드 맨 위에 굵게 |
| **누가 · 언제** | `테*트` · 처음 온 날 · 이전 메시지 몇 건 | 이름은 가운데 `*`, 번호 · 이메일은 지움. 「처음 온 분인지 자주 오는 분인지」만 |
| **문의** | 새 문의(안 읽은 고객 말)만, 가린 뒤 | 앞선 대화와 섞이지 않게 |
| **앞선 대화 요약** | 두 문장. 「입장 링크를 못 받았다고 해서 알림톡으로 보냈다고 안내했고, 받았다고 했어요」 | 2주 동안 다섯 번 오간 대화도 두 문장으로. 원문 · 날짜 인용 없음 |
| **AI 초안** 또는 **사람 확인이 필요한 것** | 초안이 있으면 초안 + 「근거: 정책 1. 다시보기 — 어디서 보나」 한 줄 / 없으면 「3일이 지났는데 안 보이면 화면 오류일 수 있어요. 신청 내역을 조회해 주세요」처럼 **뭘 확인해야 하는지** | 그냥 넘기지 않고 왜 못 썼는지 말하게 |
| **버튼** | `이대로 보내기` · `고쳐서 보내기` · `건너뛰기` · `카카오에서 열기` | 초안이 없으면 「답 써서 보내기 · 건너뛰기」 |

## 버튼을 누르면

- **이대로 보내기** → 카드가 「보내는 중 → 보냈어요(누가, 언제)」로 바뀌고, 회원 카톡에 답이 떠요.
- **고쳐서 보내기** → 창이 열리고, 고친 문장이 그대로 나가요. **고친 문장은 다음 초안의 예시가 돼요.** 쓸수록 우리 말투에 가까워져요.
- **건너뛰기** → 카드에 「건너뜀(누가)」만 남아요.
- 카카오 관리자 화면에서 직접 답해도 돼요 → 수집기가 15분 안에 알아채고 카드를 닫아요.

## 왜 슬랙 카드인가

- 카카오 관리자 화면을 안 열어도 돼요. 알림으로 오고, 답도 버튼으로 나가요.
- 답을 처음부터 쓰지 않아요. 초안과 근거가 있어요.
- 여러 명이 같이 보고, 스레드에서 상의하고, 누가 뭘 했는지 남아요.
