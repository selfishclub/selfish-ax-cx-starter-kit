# 같은 패턴, 국밥집 — 「리뷰 원터치」

> 배민 AI 장사사관학교 실전 캠프에서 부찌대학 사장님이 만든 도구예요. 배민 · 쿠팡이츠 · 네이버 리뷰를 한곳에 모으고, 답글 초안을 사장님 말투로 써 둬요.

- 스타터 키트(공개): https://github.com/selfishclub/review-onetouch-starter
- 캠프 저장소(사장님 12명): https://github.com/selfishclub/baemin-ops-os-camp

## 한 줄로

**밤에는 프로그램이 모으고 초안까지, 아침에는 사장님이 확인하고 누르기만.**

## 이 키트와 같은 자리

| | 셀피쉬클럽 CX | 리뷰 원터치 |
|---|---|---|
| 모으기 | 카카오 채널 관리자 화면을 5분마다 | 플랫폼 세 곳의 새 리뷰를 밤 10시에 |
| 초안 | 우리가 보낸 답 121개로 만든 정책 | 사장님이 써 온 답글 5,426건에서 말투 |
| 사람이 누르는 자리 | 슬랙 카드의 「이대로 보내기」 | 답글칸까지 채우고 **멈춤** — 등록 버튼은 사장님 몫 |
| 읽기 도구 | Playwright (창 없이) | Playwright (창 없이) |
| 쓰기 도구 | Playwright (승인한 글만) | Aside (사장님이 보면서 한 건씩) |
| 비밀번호 | 저장 안 함, 세션만 | 저장 안 함, 세션만 |
| 비용 | 새로 결제 없음 | 0원으로 시작 |

## 넘지 않는 선도 같아요

- 등록 버튼은 사람이 · 로그인은 사람이 창에서 · 수집은 읽기 전용 · 「비정상 동작」 문구가 뜨면 멈춤 · 한 건씩 간격을 두고 · 비밀은 올리지 않음

적정 기술 기준 세 개(이미 쓰는 도구 · 0원부터 · 사람이 누르는 자리 먼저)가 회원 1만 명 커뮤니티에서도, 국밥집에서도 똑같이 먹혀요.
