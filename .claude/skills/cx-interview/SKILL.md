# cx-interview — 나를 인터뷰해서 답변 정책 문서 만들기

## 왜 있나

AI가 문의에 답할 때 **무엇을 보고, 무슨 말을 하고, 무슨 말을 하면 안 되고, 언제 사람에게 넘기는지**를 먼저 정해야 해요. 이게 없으면 AI가 날짜 · 금액 · 조건을 지어내요. 셀피쉬클럽도 코드보다 이 문서를 먼저 만들었어요. 이 스킬은 질문 7개로 그 문서의 초안을 만들어요.

## 지키는 것

- **질문은 하나씩.** 질문 카드 도구(Claude Code `AskUserQuestion`, Codex `request_user_input`)가 있으면 그걸로. 없거나 답이 비어서 돌아오면 번호를 매겨 글로 묻고 기다린다.
- **고르기만 하면 되게.** 선택지를 주고, 「기타」로 직접 쓸 수 있게 한다. 길게 설명하라고 하지 않는다.
- **코드는 돌리지 않는다.** 파일을 쓰는 것도 마지막 승인 뒤에만.
- **이름 · 번호 · 이메일 · 금액을 묻지 않는다.** 예시 답에 그런 게 섞여 들어오면 가린 뒤에만 문서에 넣는다.
- 한 번에 한 질문. 7개가 끝나기 전에 문서를 쓰지 않는다.

## 질문 7개 (순서대로)

1. **채널과 양** — 문의가 들어오는 곳은? (카카오 채널 / 채널톡 / 인스타 DM / 네이버 톡톡 / 이메일 / 기타) 하루 몇 건쯤? (1~5 / 5~20 / 20~50 / 50+)
2. **자주 오는 유형 3~5개** — 예: 다시보기 · 링크 못 받음 · 로그인 · 환불 / 배송 · 교환 · 영업시간 · 예약 / 가격 · 재고 · 제휴. 복수 선택 + 기타.
3. **유형별 내가 실제로 보내는 답** — 2번에서 고른 유형마다 「지금 보내는 답 한 문장」을 받는다. 없으면 「아직 정해진 답 없음」으로 두고 `[확인 필요]` 표시. (보낸 답이 많으면 `cx-policy-from-history` 스킬을 권한다)
4. **말투** — 해요체 / 합니다체, 이모지(안 씀 / 문장 끝에 하나), 사과 방식(한 번만 + 다음 할 일), 고객 이름을 부르는지.
5. **절대 자동화하지 않을 것** — 복수 선택: 환불 · 결제 · 정산 / 개인정보 조회 · 변경 / 처리 여부 약속(되는지 · 언제 되는지) / 가격 · 할인 협상 / 컴플레인 / 기타. 여기서 고른 건 AI가 초안을 쓰지 않고 사람에게 넘긴다.
6. **확인이 있어야 답할 수 있을 때 보내는 첫 문장** — 예: 「안녕하세요! 신청하실 때 적으신 성함/연락처(뒷 4자리) 알려주시면 확인 후 안내드리겠습니다 :)」. 기본 문장을 주고 고치게 한다.
7. **카드를 받을 곳과 확인 간격** — 슬랙 / 디스코드 / 텔레그램 / 이메일, 그리고 몇 분마다(5 / 15 / 30 / 60). 카드를 같이 볼 사람이 있는지.

## 끝나면 만드는 것 (승인 뒤에)

1. 먼저 **표로 미리 보여준다** — 「항목 · 들어갈 내용 · 근거(몇 번 답)」 세 칸. 「이대로 쓸까요?」
2. 승인되면:
   - `policy/answers.md` — `policy/answers.template.md` 틀 그대로. 말투(4) · 절대 하지 않는 것(5) · 첫 반응 A(6) · 유형별 표준 답(2 · 3, 없는 건 `[확인 필요]`) · 확인 필요로 넘겨야 하는 경우(5). 머리말에 「이 문서에 없는 내용은 초안기가 지어내지 않고 확인 필요로 넘긴다」를 그대로 둔다.
   - `policy/leak-words.json` — `policy/leak-words.example.json`을 바탕으로, 사용자가 쓰는 내부 도구 · 업체 · 시스템 이름을 물어 더한다(예: 발송 툴 · DB · 어드민 · 운영진 실명).
   - **「사람이 누르는 자리」 한 줄** — answers.md 맨 위에: 「발송은 (슬랙)에서 사람이 버튼을 눌러야만 나간다. (5)번에 고른 건 AI가 초안을 쓰지 않는다.」
3. 마지막에 「지금 할 일」 세 줄: ① answers.md의 `[확인 필요]` 칸 채우기(이게 병목이에요) ② START_HERE 프롬프트 B로 수집기 설계 받기 ③ 실제 발송은 꺼 둔 채로 시작하기.

## 하지 않는 것

- 정책에 없는 날짜 · 금액 · 조건을 대신 채워 넣지 않는다. 모르면 `[확인 필요]`.
- 사용자가 5번에서 고른 항목을 「이 정도는 자동화해도 되지 않냐」고 설득하지 않는다.
- 수집기 코드 · 슬랙 앱 설정을 이 스킬 안에서 시작하지 않는다. 그건 프롬프트 B.
