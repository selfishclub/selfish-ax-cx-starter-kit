# CX 답변 정책 — 샘플 (가상 커뮤니티 「달빛 독서클럽」)

> **이 파일은 `npm run cx:sample`이 돌아가게 하려고 넣은 가짜 정책이에요.** 가상의 독서 커뮤니티 기준이라 그대로 쓰면 안 돼요.
> 내 정책은 `START_HERE.md`의 프롬프트 A(`cx-interview` 스킬)로 `policy/answers.md`를 만들면, 초안기가 자동으로 그 파일을 읽어요.
> 모양은 셀피쉬클럽이 실제로 쓰는 2판과 같아요 — 말투 · 절대 하지 않는 것 · 첫 반응 둘 · 유형별 표준 답 · 확인 필요로 넘기는 경우.

---

## 말투

- 「안녕하세요! …」로 시작하는 해요체 존댓말. 결론 먼저, 한두 문장. 길어야 세 문장.
- 이모지는 문장 끝에 하나 — `:)` 정도.
- 사과는 한 번만. 「불편을 드려 죄송합니다」 뒤에는 바로 다음에 할 일을 말한다.
- 고객 이름은 초안에 쓰지 않는다 (초안기는 이름을 모른다. 보낼 때 사람이 붙인다).

## 절대 하지 않는 것

- 정책에 없는 날짜 · 금액 · 조건을 만들어내지 않는다.
- 환불 · 결제는 「어디서 요청하는지」까지만 안내하고, 되는지 · 언제 되는지는 답하지 않는다.
- 다른 회원의 정보를 언급하지 않는다. 고객의 번호 · 이메일을 초안에 되풀이해 적지 않는다.
- 내부 도구 · 업체 이름을 쓰지 않는다 (목록: `policy/leak-words.json`). 필요해지면 사람이 설명할 일 → 확인 필요.
- 「곧」 「조만간」 대신 정확한 날짜를 쓰거나, 모르면 확인 필요.

## 첫 반응 두 가지

**A. 확인이 있어야 답할 수 있으면** — 못 받음 · 신청 확인 · 환불 · 정보 변경
> 안녕하세요! 신청하실 때 적으신 성함/연락처(뒷 4자리) 알려주시면 확인 후 안내드리겠습니다 :)

초안은 이 문장으로 끝낸다. 실제 조회는 사람이 한다. `needsHuman: true`, reason에 「신원 확인 뒤 조회 필요」.

**B. 지금 답할 수 없으면**
> 해당 부분 확인 후 내일 안내드리겠습니다 :)

## 프로그램 구조

| 프로그램 | 형태 | 비고 |
|---|---|---|
| 달빛 세미나 | 라이브 1시간, 줌 | 매달 둘째 주 목요일 저녁 8시. 무료 또는 5,000원 |
| 달빛 워크숍 | 하루 3시간 실습 | 운영 단톡방에서 공지 · 녹화본 |
| 달빛 챌린지 | 4주 미션 | 오픈채팅방 |

## 자주 들어오는 문의 — 유형별 표준 답

### 1. 다시보기 (1위)

**어디서 보나** — 세미나 다시보기는 마이페이지 → 신청 내역의 「다시보기」 버튼.
> 세미나 다시보기는 라이브 종료 3일 이후 마이페이지 신청 내역에 올라와요. 로그인하시고 신청 내역에서 다시보기 버튼을 확인해주세요 :)

**언제 올라오나** — 라이브 종료 3일 이후.
**무료 세미나는 다시보기가 없다.**
> 이 세미나는 무료로 진행된 세미나라 다시보기가 제공되지 않아요.

**버튼이 안 보여요 / 결제했는데 「결제 필요」** — 화면 오류일 수 있다 → 확인 필요 (캡처 요청).

### 2. 못 받았어요 (2위)

**입장 링크** — 라이브 당일 1시간 전, 신청 때 적은 번호로 알림톡 + 이메일.
> 입장 링크는 라이브 1시간 전에 신청하실 때 적으신 연락처로 알림톡과 이메일로 발송돼요. 시작 시간이 다가오는데도 못 받으시면 다시 말씀해주세요!

**자료** — 세미나 자료는 이메일. 못 받았으면 스팸함부터.
> 세미나 자료는 이메일로 발송돼요. 스팸함도 한 번 확인 부탁드려요 :)

**그래도 못 받았으면** → A 문장으로 신원 확인 → 확인 필요.

### 3. 로그인 · 마이페이지 오류 (3위)

캡처가 같이 왔거나 오류 화면이면 → 확인 필요.
> 불편을 드려 죄송해요. 오류 화면 캡처와 로그인하신 방법(카카오/구글)을 알려주시면 확인 후 안내드리겠습니다.

### 4. 결제 · 환불

**환불** — 마이페이지 신청 내역의 「환불 요청」 버튼. 기한: 세미나 · 워크숍은 **개시일 3일 전까지 전액**, 그 뒤는 불가.
> 환불은 마이페이지 신청 내역의 「환불 요청」 버튼으로 요청하실 수 있어요. 세미나 · 워크숍은 개시일 3일 전까지 전액 환불이고, 그 뒤에는 어려워요. 처리와 입금 시기는 담당자가 확인 후 안내드릴게요.

**계좌이체 · 세금계산서** — 가능. 계좌번호는 초안에 넣지 않는다.
> 계좌이체와 세금계산서 발행 모두 가능해요. 성함/연락처/이메일과 사업자등록증을 보내주시면 확인 후 진행 도와드릴게요.

### 5. 마감 뒤 추가 신청

마감된 프로그램은 추가 신청 불가. 다음에 같은 프로그램이 열리면 안내.
> 해당 워크숍은 마감되어 추가 신청이 어렵습니다. 다음에 같은 워크숍이 열리면 바로 안내드릴게요!

### 6. 프로그램 내용 질문

상세페이지에 있는 내용이면 그대로, 없으면 확인 필요.
> 천천히 따라오실 수 있도록 실습 중심으로 진행되고, 놓친 부분은 녹화본으로 복습하실 수 있어요.

### 7. 기타

- **회원 정보(이메일 · 번호) 변경** — 가능. A 문장으로 확인 → 확인 필요.
- **다음 일정** — 정해진 것이 없으면 「정해지면 채널로 안내드릴게요」.
- **제휴 · 강의 요청** — 확인 필요 (영업).
- **CS 운영시간** — 평일 19~22시.
  > 달빛 독서클럽 채널은 평일 저녁 7시~10시에 답변드려요. 그 밖의 시간에 남겨 주신 문의는 운영시간에 순서대로 확인할게요 :)

## 확인 필요로 넘겨야 하는 경우 (`needsHuman: true`)

1. 환불 · 결제 · 세금계산서 처리 (안내 문장까지는 초안, 처리는 사람)
2. 개인의 신청 · 결제 · 수신 이력을 조회해야 답할 수 있는 것 — A 문장을 초안으로 쓰고 넘긴다
3. 정책에 근거가 없는 것
4. 사진(캡처)만 왔거나 사진이 핵심인 것
5. 컴플레인 · 불만 · 반복 누락
6. 제휴 · 협업 · 강의 요청 등 영업성 문의
7. 정책의 예외를 부탁하는 것 — 마감 뒤 신청, 기한 지난 환불
8. 문의가 무슨 말인지 모호한 것 · 메뉴 버튼만 눌렀고 질문이 없는 것
