# 05 · 넘지 않는 선 — AI한테 절대 안 맡긴 네 가지

> 말로만 「하지 마」라고 한 게 아니라, **버튼을 안 누르면 안 나가게** 만들었어요.

| | 무엇 | 어떻게 막았나 |
|---|---|---|
| **① 발송** | 고객에게 나가는 말 | 사람이 카드에서 「이대로 보내기 / 고쳐서 보내기」를 눌러야만 나가요. 비상 스위치(`CX_SEND_ENABLED=false`) 하나로 발송 전체를 꺼요. 처음 켤 땐 꺼진 채로. |
| **② 배포** | 사이트 · 정책 문서 반영 | AI는 수정안(PR)을 **올리기까지만.** 반영(Merge) 버튼은 사람이. 정책 문서를 AI가 직접 덮어쓰지 않아요. |
| **③ 돈** | 환불 · 결제 · 정산 | 되는지 · 언제 되는지는 답하지 않아요. 「어디서 요청하는지」까지만. 이런 낱말이 문의에 있으면 **AI에 보내지도 않고** 바로 사람에게. |
| **④ 개인정보** | 이름 · 번호 · 이메일 · 금액 | AI와 슬랙이 보기 **전에** 가려요. 회원 DB는 아예 열지 않아요. 학습할 때도 가린 사본만. 로그에는 번호와 결과만. 원본은 카카오 관리자 화면에만. |

## 맡긴 글쓰기는 딱 네 군데

1. 홈페이지 채팅 답 (회원이 물어보면)
2. 카카오 답 **초안** (사람이 보내기 전까지)
3. 아침 브리핑의 「고칠 것 하나」 제안
4. 일요일 학습의 「규칙을 이렇게 고칠까요」 수정안

나머지(카카오 읽기 · 이름 가리기 · 카드 올리기)는 **정해 둔 규칙대로** 돌아요. AI가 판단하지 않아요. 되돌릴 수 없는 건(카톡 보내기 · 배포 · 환불 · DB 바꾸기) 사람이 해요.

## 새면 안 되는 말

답에 내부 용어가 섞이면 **내보내지 않고 사람에게** 넘겨요. 목록은 [`policy/leak-words.example.json`](../policy/leak-words.example.json). 도구 · 업체 · 시스템 이름(발송 툴 · 자동화 툴 · DB · 어드민 · 크레딧 · API 키 · 환경변수 …), 장애 원인, 회원 수, 매출, 운영진 실명, 아직 안 연 기능.

## 그 밖에

- **DB를 바꾸는 SQL도 사람이 실행해요.** 「이 SQL이 뭔데? 말로 설명해 줘」를 먼저 물어요.
- **비밀번호 · API 키 · 토큰은 채팅에 붙여 넣지 않아요.** `.env.local`에 사람이 직접 넣고, 코드는 이름으로만 읽어요. `.env.example`엔 이름만.
- **브라우저 로그인은 사람이 창에서.** 세션 폴더(`auth-state/`)와 문의 기록(`cx-data/`)은 깃에 올리지 않아요(`.gitignore`).
- **카카오에서 직접 답해도 돼요.** 사람이 관리자 화면에서 바로 답하면 카드는 15분 안에 저절로 닫혀요.
- **AI 학습 사용은 꺼 뒀어요.** (Claude 설정)
