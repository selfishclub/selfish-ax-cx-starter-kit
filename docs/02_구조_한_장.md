## 칸마다 한 줄

| 칸 | 무엇 | 지키는 것 |
|---|---|---|
| 수집기 | 안 읽은 문의만, 5분마다, 창 없이 | 읽기 전용. 비밀번호 저장 안 함, 세션만 |
| 가리기 | 이름 · 번호 · 이메일 · 긴 숫자 · 금액 | AI와 슬랙이 보기 **전에**. 원본은 관리자 화면에만 |
| 맥락 읽기 | 새 문의와 앞선 대화를 가르고, 앞선 대화는 두 문장으로 | 날짜 · 원문 인용 없이, 해요체. 같은 방이라도 새 메시지가 오면 새 카드 |
| 판별 · 초안 | 정책 문서 + 최근 보낸 답 10건을 보고 | 근거 없으면 쓰지 않음. 근거를 한 줄 붙임 |
| 카드 | 슬랙 한 곳에서. 크루도 같이 봄 | 누가 뭘 보냈는지 카드에 남음 |
| 발송 | 사람이 누른 것만 | 비상 스위치 하나로 전체 OFF |
| 브리핑 | 매일 아침 한 장 | 제안 한 줄까지 |
| 학습 | 일요일 밤, 정책 문서를 고치자는 PR | AI가 직접 덮어쓰지 않음. 모델 훈련이 아니라 문서 고치기 |

## 만든 순서 (한 번에 만든 게 아니에요)

1. **버전 1 — 일단 돌아가게**: 카카오를 읽을 수 있나(제일 불확실한 것)부터 → 정책 문서는 뼈대만 → 읽기 → 초안 → 슬랙 카드. 이때는 승인을 눌러도 카카오로 안 나갔어요.
2. **버전 2 — 실제로 쓰기 시작**: 이전에 보낸 답으로 정책 문서 구체화 → 이름 · 번호 가리기 → 최근 보낸 답 10건을 예시로 → 발송 붙이기.
3. **쓰면서 고친 것**: 로그인이 풀리면 슬랙으로 알림 → 카카오에서 직접 답하면 카드 닫기 → 살아 있는지 보는 대시보드 → 맥락 요약.
