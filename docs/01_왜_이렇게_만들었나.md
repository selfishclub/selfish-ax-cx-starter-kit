# 01 · 왜 이렇게 만들었나

## 카카오 채널은 문의를 꺼내 주는 API가 없어요

카카오 채널 1:1 채팅은 **수신 API가 없어요.** 두 번 물어봤고 답도 받았어요. 상담톡 API는 공식 딜러사를 끼고 유료로만 쓸 수 있어서 직접 접근이 안 돼요.

그래서 사람이 하던 대로 했어요. **프로그램이 관리자 화면을 대신 열어서, 안 읽은 문의만 5분마다 읽어요.** 창은 띄우지 않아요(띄우면 마우스를 뺏겨서 다른 일을 못 해요). 비밀번호는 어디에도 저장하지 않고, 사람이 한 번 직접 로그인한 세션(출입증)만 내 컴퓨터에 둬요.

도구는 Playwright를 썼어요. 사람 대신 브라우저를 열고, 누르고, 읽는 프로그램이에요. 추천받아 썼고, 무료고, 맥과 윈도우 다 돼서 안 바꿨어요. Aside · ego lite 같은 브라우저 에이전트로 바꿔도 돼요 → [04](04_다른_채널_다른_도구.md).

> 이메일 · 채널톡 · 인스타 DM · 네이버 톡톡은 공식 API가 있어서 **카카오 채널보다 오히려 쉬워요.** 이 키트의 어려운 부분(화면 읽기)이 통째로 빠져요.

## 적정 기술 — 기준 세 개

AI 월드는 아침에 눈 뜨면 바뀌어 있어요. 새 걸 쫓는 대신 **적정 기술**을 고르는 기준을 정해 뒀어요.

| 기준 | 우리 선택 |
|---|---|
| **① 이미 쓰는 도구에 붙인다** | 새 앱을 만들지 않고 **슬랙 카드**로. 매일 쓰는 도구라 새로 배울 게 없어요. 카카오 채널도 원래 쓰던 창구 그대로. |
| **② 0원부터** | Playwright 0원 · 슬랙 무료 · 카카오 채널 무료 · Claude는 이미 내던 구독(API 키 없이 Claude Code CLI로). **이 워크플로우 때문에 새로 결제한 건 없어요.** |
| **③ 사람이 누르는 자리를 먼저 정한다** | 뭘 자동화할지보다 **뭘 절대 자동화 안 할지**부터. 발송 · 돈 · 개인정보 · 배포 → [05](05_넘지_않는_선.md). |

이 기준은 회원 1만 명 커뮤니티에서도, 국밥집에서도 똑같이 먹혀요 → [`examples/review-onetouch.md`](../examples/review-onetouch.md).

## 쓴 도구와 돈

| 도구 | 하는 일 | 비용 |
|---|---|---|
| Claude Code | 초안 · 브리핑 · 만드는 일 전부 | 이미 내던 구독 (`CX_AI_PROVIDER=cli`, API 키 불필요) |
| Playwright | 카카오 채널 관리자 화면 읽기 · 답 입력 | 무료 |
| Slack | 문의 카드 · 아침 브리핑 | 무료 |
| 카카오톡 채널 | 문의 창구 | 무료 |
| 맥 한 대 | 수집기가 사는 곳 (로그인 시 자동 시작) | 있던 것 |

> 구독(CLI)으로 돌리면 건당 토큰이 API 직접 호출보다 커요. 추가 청구는 없지만 구독 사용량을 써요. 문의량이 늘면 `api`로 전환하면 돼요.

## 코드보다 정책 문서가 먼저

처음에 Claude Code에 한 말은 코드 얘기가 아니었어요. 순서는 이랬어요.

1. 뭘 만들고 싶은지 한 장 — 「한 명이 운영하는데, 운영 전체를 비서처럼 챙겨주는 OS. 반복적으로 챙겨야 하는 일을 자동화하고 싶다.」
2. 하면 안 되는 일부터 선 긋기 — 「카카오 채널에 이상한 메시지 보내거나 다른 짓 하면 안 돼. 그냥 읽기만 해야 돼.」
3. 보낸 답 분석 — 「기존에 답변했던 것들을 싹 살펴보고 정책과 비교하면서 유형별로 나눠 봐.」
4. 규칙 — 「초안을 만들 때 1. 어떤 데이터를 기준으로 하고 2. 무슨 말을 하고, 무슨 말을 하면 안 되는지, 규칙을 어떻게 만들지?」
5. 발송 — 「승인 눌러도 안 간다는 거지? 그럼 언제부터 발송돼? 내가 발송 시점 정하고 싶어.」
6. 배우게 — 「새로 들어오는 문의를 알아서 배우게 못 해? 특정 주기를 기준으로.」
7. 보이게 — 「이런 상태들을 모니터링하는 대시보드 같은 거 만들어 줘.」

그래서 이 키트도 **정책 문서(인터뷰)가 먼저**고, 코드는 그다음이에요.
